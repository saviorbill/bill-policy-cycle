# 经济状态仪表盘（宏观数据表）

## 用途

这些宏观数据不是"政策定调"本身，而是三件事的输入：

1. 政策反应函数：判断政策往哪边走
2. 倒逼信号：给概率评估提供"倒逼"维度打分
3. 传导验证：政策是否见效（防日本式流动性陷阱）

## 三、日本判断清单当前状态（重要修正）

| 观察指标   | 当前状态                        | 判断     |
| ------ | --------------------------- | ------ |
| 居民去杠杆  | 无直接数据（地产 -27.2% 间接反映购房意愿极弱） | 偏危险    |
| M1 增速  | 3.2%，持续回落                   | **危险** |
| 地产投资   | -27.2%，深度收缩                 | **危险** |
| 财政加杠杆  | 积极财政 + 准财政 8000 亿           | 健康     |
| 企业资本开支 | 固投 -7.2%，投资全面收缩             | **危险** |

### 修正后的综合判断

5 个指标里 4 个偏"危险"，内需投资端已呈现**资产负债表衰退特征**（企业只收缩不投资、地产深度收缩、M1 低迷）。

**但有一个关键区别**：外需强劲（出口 +36.3%）是日本当年没有的缓冲。日本 1990 年代是"内外需双弱"，中国当前是"内需塌、外需强"。

结论：内需端在向日本式衰退滑移，但外需缓冲使经济未全面陷入停滞。**政策的关键是财政主动加杠杆托底内需（日本教训：光靠货币没用），而不是继续依赖出口。**

## 四、与打分卡的关系

- 打分卡看"政策松紧"；仪表盘看"经济状态"
- 当前组合：内需深度收缩（投资/地产/M1 全线走弱）+ 外需强 + 政策结构性宽松 → 内需倒逼政策加码的信号非常强
