# 通稿解读模板

## 元信息

- 会议 / 文件名称、日期、类型（政治局会议 / 中央经济工作会议 / 国常会 / 货政报告 / 其他）

## 结构化提取字段

1. 总基调：定调措辞（如"稳中求进""以进促稳""更加积极有为"）
2. 经济判断：对当前经济的表述（"回升向好" vs "下行压力加大"）
3. 政策目标：稳增长 / 防风险 / 调结构 的优先级排序
4. 货币政策措辞：宽松 / 中性 / 收紧（记录关键词）
5. 财政政策措辞：力度、赤字、专项债、特别国债
6. 产业政策：点名扶持 / 整顿的行业
7. 监管 / 资本市场：融资节奏、防风险、资本市场表态
8. 增量信息：相比上次会议的新表述、新工具、新目标

## 增量信息标记

- 新增 / 上调 / 下调 / 符合预期
- 对应打分卡哪个维度

## 落地动作

提取后 → 更新 `models/政策周期打分卡.md` 对应维度 → 记录变更日期
