# 历史周期类比库

## 用途

把当前周期与历史类比，判断"现在处在周期哪个阶段、后面会怎么走"，并为概率评估提供历史先验（历史频率）。参照系分三层：中国 2000 年以前、中国 2000 年以后、日本（国际参照）。

---

## 一、中国政策周期数据表（2000 年以前）

| 周期        | 触发背景                 | 政策动作序列                       | 结果 / 市场                                |
| --------- | -------------------- | ---------------------------- | -------------------------------------- |
| 1988      | 价格闯关引发抢购潮            | 治理整顿、紧缩信贷                    | CPI 冲高至 18.8%，1989 全面治理                |
| 1992-1993 | 邓南巡后经济过热、"三乱"        | 朱镕基宏观调控：1993.6 金融紧缩十六条、整顿乱集资 | 1993 CPI 14.7%                         |
| 1993-1996 | 治理通胀                 | 连续加息、信贷紧缩、"软着陆"              | 1994 CPI 24.1% 峰值 → 1996 降至 8.3%，软着陆成功 |
| 1997-1999 | 亚洲金融危机、通缩压力          | 政策急转：由紧缩转向"积极财政 + 稳健货币"      | 1998 首次发行 1000 亿长期建设国债，启动积极财政          |
| 1999-2002 | 通缩持续（1999 CPI -1.4%） | 持续积极财政、多次降息、长期建设国债           | 2002 后经济回升                             |

### 这段历史的核心价值

- 1993-1996 是中国政策周期里最经典的一次"果断收紧治理过热"：说明政策转向坚决时，能有效压住通胀、实现软着陆
- 1997-2002 是中国第一次"治理通缩"：用了积极财政（发国债搞基建）+ 稳健货币，是当前应对通缩最直接的本土参照

## 三、日本案例（国际参照）

日本是研究"政策长期宽松失效、通缩、资产负债表衰退"最关键的镜子，对当前中国高度相关。

### 政策时间线（关键节点）

| 时间            | 事件                 | 政策动作                 |
| ------------- | ------------------ | -------------------- |
| 1985.9        | 广场协议               | 日元大幅升值               |
| 1986-1989     | 资产泡沫膨胀             | 连续降息至 2.5%，持续低利率     |
| 1989.5-1990.8 | 刺破泡沫               | 连续加息至 6%             |
| 1989.12       | 日经 225 见顶（38957 点） | —                    |
| 1991          | 泡沫破裂               | 资产价格崩盘、开始降息          |
| 1990s         | 失去的十年              | 持续降息，通缩形成            |
| 1999.2        | 零利率政策              | 世界首次 ZIRP            |
| 2000.8        | 过早退出               | 解除零利率（公认失误，通缩复燃）     |
| 2001.3        | 量化宽松               | 世界首次 QE              |
| 2006          | 退出 QE              | —                    |
| 2013.4        | 安倍经济学              | QQME（第一支箭），目标 2% 通胀  |
| 2016.1        | 负利率                | -0.1%                |
| 2016.9        | YCC                | 收益率曲线控制（10年期国债锚定 0%） |
| 2024.3        | 退出宽松               | 结束负利率+YCC，17 年来首次加息  |
| 2024-2025     | 货币政策正常化            | 逐步加息                 |

### 对中国的启示（关键提炼）

1. 资产负债表衰退（辜朝明）：泡沫破裂后，企业与家庭"优先还债"而非借贷扩张，即使零利率也没人借钱 → 货币政策失效（流动性陷阱）。这是中国当前地产去杠杆要警惕的最大风险。
2. 政策反复的代价：日本 1990 加息刺破泡沫后降息太慢，且 2000 年过早退出零利率，导致通缩反复、无法摆脱。教训：宽松要果断，退出要慎之又慎。
3. 货币放水不等于结构改革：安倍三支箭，前两支（货币+财政）打了，第三支（结构改革）始终没落地，导致长期宽松却效果递减。教训：光靠货币政策解决不了结构性问题。
4. 长期宽松的退出极难：日本花了约 30 年才敢退出负利率，且退出极缓慢。教训：进入通缩容易、出来难，政策要有前瞻性。

## 四、五要素复盘法

每轮记录五要素：背景 → 触发信号 → 政策动作序列 → 市场表现 → 退出/转向信号。

## 五、关键历史规律（用于先验概率）

1. 宽松一旦开启，通常是连续动作（降准→降息→结构性工具→财政加码），很少"一次到位"
2. 政策退出/转向信号，比政策加码信号更值得警惕（决定周期反转）
3. 全面降息与结构性工具常交替：总量空间收窄时，转向结构性、精准支持
4. 年末/年初（跨年流动性+开门红）是降准高发窗口
5. 治理通缩比治理通胀难得多（参照日本与 1997-2002 中国）：财政主动托底是关键
