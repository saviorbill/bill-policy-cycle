# 政策周期打分卡

## 一、六维打分（每维 -2 强收紧 ~ +2 强宽松）

| 维度      | 观察点           | 打分依据示例                         |
| ------- | ------------- | ------------------------------ |
| 1. 总基调  | 定调措辞          | "更加积极有为"=+2，"稳中求进"=0，"防止过热"=-2 |
| 2. 货币   | 利率方向、流动性、降准降息 | 连续降准降息=+2，中性=0，加息/紧流动性=-2      |
| 3. 财政   | 赤字、专项债、特别国债   | 提高赤字+特别国债=+2，持平=0，压缩=-2        |
| 4. 产业   | 扶持 vs 整顿      | 密集扶持=+2，中性=0，整顿=-2             |
| 5. 监管   | 防风险 vs 鼓励     | 鼓励创新=+2，中性=0，强监管=-2            |
| 6. 资本市场 | 融资节奏、平准资金     | 暂停IPO+平准资金=+2，中性=0，收紧=-2       |

## 二、政策宽松度指数

宽松度指数 = 六维加权得分之和（可给货币、财政更高权重）。

- 指数 > 0 且上升：宽松期，利好成长 / 长久期资产
- 指数 < 0 且下降：收紧期，利好防御 / 价值
- 指数拐点：政策周期转向的关键信号

## 三、措辞词典（关键词 → 松紧映射）

### 货币政策

- 宽松：适度宽松、更加积极、加大力度、降准降息、合理充裕、有力
- 中性：稳健、灵活适度、精准有力、均衡
- 收紧：从紧、管好货币总闸门、防止大水漫灌

### 财政政策

- 宽松：更加积极、提高赤字率、超长期特别国债、加力提效
- 中性：积极、提质增效、优化结构
- 收紧：过紧日子、压减

### 定调

- 宽松：以进促稳、先立后破、更加积极有为、超常规逆周期调节
- 中性：稳中求进、稳字当头
- 收紧：防过热、去杠杆

## 四、周期位置判断（三维定位）

1. 当前政策目标重心：稳增长 / 防风险 / 调结构 哪个优先
2. 宽松度指数处于周期哪个阶段：初期 / 中期 / 后期
3. 与历史哪一轮周期最像（见 `cases/历史周期类比库.md`）

## 五、使用示例（演示打分怎么落）

以"924 一揽子政策"（2024 年 9 月 24 日降准降息 + 资本市场工具 + 地产政策）为例：

- 货币：降准 0.5pct + 降息 = +2
- 财政：后续增发 + 化债 = +1
- 资本市场：创设互换便利/回购增持再贷款、平准表态 = +2
- 总基调：从"稳中求进"转向"加力" = +1
- 结论：宽松度指数由负转正，周期进入宽松初期，利好权益与长久期资产
