# 政策路径概率评估

## 用途

把"下一步会出什么政策"的定性判断，升级为可复核的概率估计。核心思想：后验概率 = 历史先验 + 当前信号修正（主观贝叶斯）。

## 一、评估前先定义清楚

- 评估的事件（如"未来3个月 LPR 下调"）
- 时间窗口（1个月 / 3个月 / 半年）
- 动作主体（央行 / 财政 / 监管）

## 二、四信号积分卡（通用工具）

对候选政策动作，四个信号各打分（0-100%），加权求和：

| 信号   | 权重  | 含义                           | 数据来源         |
| ---- | --- | ---------------------------- | ------------ |
| 历史先验 | 40% | 历史上"类似周期位置"下，该动作在窗口内发生的频率    | 历史周期类比库      |
| 吹风信号 | 20% | 高层/央行是否已表态（措辞松紧）             | 会议通稿、讲话      |
| 资金信号 | 20% | DR007/国债收益率是否已先行变化（市场是否已在定价） | 市场利率         |
| 倒逼信号 | 20% | 经济数据是否恶化到"倒逼"政策出手            | PMI/通胀/地产/就业 |

总概率 = 历史先验×40% + 吹风×20% + 资金×20% + 倒逼×20%

## 三、概率档位与含义

| 概率     | 档位 | 含义          |
| ------ | -- | ----------- |
| <30%   | 低  | 不押注         |
| 30-60% | 中  | 可小仓位博弈、列入观察 |
| >60%   | 高  | 可重点配置       |

## 四、概率档位与资产含义映射

| 政策动作               | 对资产的含义            |
| ------------------ | ----------------- |
| 全面降息（LPR下调）        | 利好长久期资产、成长股、债券    |
| 降准                 | 利好流动性敏感品种、券商      |
| 结构性工具（定向支持制造业/出口链） | 利好对应行业，但对总量估值拉动有限 |
| 财政加码（特别国债/专项债）     | 利好基建、顺周期          |

## 五、使用约定

- 概率是"主观贝叶斯"，价值在于把模糊判断结构化、可事后复盘，不是精确数学
- 每次评估记录：事件、窗口、四信号打分、总概率、事后结果
- 持续校准：把"事后结果 vs 当时概率"做回测，修正各信号权重

## 六、示范（2026年10月底时点，基于公开信息）

背景：LPR连续12个月未动；货币政策重心从总量宽松转向结构性支持；利率锚由7天逆回购转隔夜；9月制造业PMI重返扩张（外需强），消费投资偏弱。

### 示范1：未来3个月"LPR全面下调"概率

- 历史先验 30%（宽松周期中，但LPR久未动+利率锚转换，全面降息频率下降）
- 吹风 40%（"适度宽松"仍在，但表述转向"精准有效"）
- 资金 40%（LPR不动，资金面中性）
- 倒逼 30%（PMI回升、外需强，未到倒逼全面降息）
- 总概率 ≈ 34%（中偏低，与机构"全面降息概率下降"一致）

### 示范2：未来3个月"降准"概率

- 历史先验 40%（跨年流动性窗口常降准）
- 吹风 50%（"降准降息仍有可能"）
- 资金 45%
- 倒逼 45%（年末流动性需求）
- 总概率 ≈ 44%（中等，高于降息）

### 示范3：未来3个月"结构性工具加码"概率

- 历史先验 50%
- 吹风 70%（明确"结构性支持""精准有效"）
- 资金 55%
- 倒逼 55%（消费投资弱，需定向支持）
- 总概率 ≈ 56%（最高，与"重心转结构性"一致）

> 结论：当前时点，结构性工具加码概率 > 降准概率 > 全面降息概率。配置含义：总量估值抬升空间有限，重心在"产业景气+政策适配"方向（如出口链、制造业）。

## 七、日本教训 → 中国当前判断清单

判断"中国会不会重蹈日本资产负债表衰退"，不看降息概率，看这几个观察指标：

| 观察指标   | 危险信号（趋日本）       | 健康信号（避开日本）     |
| ------ | --------------- | -------------- |
| 居民去杠杆  | 提前还贷加速、居民信贷持续负增 | 居民信贷企稳回升       |
| M1 增速  | 长期低迷甚至负增长       | M1 回升、企业活期存款增加 |
| 地产销售   | 持续下滑、库存高企       | 销售企稳、价格止跌      |
| 财政加杠杆  | 财政谨慎、不敢赤字       | 财政主动托底、赤字率提升   |
| 企业资本开支 | 只还债不投资          | 资本开支回升         |

判断逻辑：

- 若前4项大多偏"危险"→ 资产负债表衰退风险高，政策需财政主导而非货币
- 若财政主动加杠杆 + 地产企稳 → 大概率能避开日本路径
