# 制图模版说明（Kimi Work · matplotlib 统一规范）

> 本规范用于所有后续数据图表制作，适用于宏观月报、行业研究、个股分析等场景。  
> 配套骨架代码：`chart_template.py`（复制后改数据即可出图）。

---

## 一、运行环境与必备初始化

所有绘图脚本在 Kimi Work 工作区内用 `python` 运行。**脚本开头必须包含以下初始化块**，缺一不可：

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(sys.executable).parent.parent.parent))
from daimon_runtime import setup_plot

import matplotlib.pyplot as plt
import numpy as np

setup_plot()  # 无参调用，启用 CJK/微软雅黑 字体支持
```

- `setup_plot()` 在**每次新建 fig 之前调用一次**（多图脚本中每张图前都调用）。
- 不调用 `setup_plot()` 会导致中文显示为方框（豆腐块）。

## 二、配色规范

### 2.1 主色板（固定常量，所有脚本统一引用）

| 角色       | 色值                                | 用途                       |
| -------- | --------------------------------- | ------------------------ |
| 主色 · 深红  | `#8B0000`                         | 第一数据系列 / 强调数据 / 排名第一项    |
| 次色 · 深灰  | `#4A4A4A`                         | 第二数据系列 / 坐标轴文字 / 数据来源文字  |
| 辅助色 · 金色 | `#C9A227`                         | 第三数据线 / 特殊标注框 / 缺口等提示性数值 |
| 标题黑      | `#1a1a1a`                         | 图表标题 / 数值标注文字            |
| 辅助红      | `#B22222`                         | 饼图/分组图的第四项               |
| 辅助灰      | `#696969` / `#808080` / `#999999` | 饼图多分类的后续项、普通排名项          |
| 浅灰填充     | `#E8E8E8`                         | "其他"类别 / 占位              |
| 浅红填充     | `#E8D5D5`                         | 对比辅助项                    |

### 2.2 背景与辅助元素

| 元素      | 规范                                                                            |
| ------- | ----------------------------------------------------------------------------- |
| 画布/图表背景 | 纯白（`facecolor='white'`、`ax.set_facecolor('white')`）                           |
| 网格线     | 淡灰 `#999999`，`alpha=0.25`，`zorder=0` 且 `ax.set_axisbelow(True)`，**必须压在数据层下方** |
| 边框      | 隐藏上、右边框（`ax.spines['top'].set_visible(False)` / `right` 同理）                   |
| 阶段背景色块  | 极淡色（如 `#F5F5F5`、`#FFF8E1`、`#FFEBEE`），只作区分，不喧宾夺主                               |

## 三、字体与字号规范

| 元素        | 字号    | 字重                         | 颜色                    |
| --------- | ----- | -------------------------- | --------------------- |
| 图表标题      | 16    | **加粗** `fontweight='bold'` | `#1a1a1a`，`pad=15~20` |
| 轴标签 / 刻度 / 图例 / 数值标注 / 注释 / 数据来源 | 15 | 常规 | 默认 / `#4A4A4A` |
| 大字号关键数值   | 15    | 加粗                         | `#1a1a1a`             |

时间范围标注格式统一为：`YYYY.MM — YYYY.MM`（如 `2015.01 — 2026.06`）。

## 四、通用绘图骨架（每张图的标准流程）

```python
setup_plot()
fig, ax = plt.subplots(figsize=(12, 7), facecolor='white')
ax.set_facecolor('white')

# ---- 绘图主体（各图型见下节） ----

ax.grid(axis='y', alpha=0.25, color='#999999', zorder=0)   # 柱状/折线图用 y 轴网格
ax.set_axisbelow(True)                                      # 网格压在数据下方
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.set_title('标题', fontsize=16, fontweight='bold', color='#1a1a1a', pad=15)
ax.legend(loc='upper left', fontsize=15, framealpha=0.9,
          facecolor='white', edgecolor='#cccccc')           # 图例左上角白底框

# 数据来源：放在图表外部、时间轴正下方（y 取 -0.02 或 0.02）
fig.text(0.5, -0.02, '数据来源：XXX', ha='center', fontsize=15, color='#4A4A4A')

plt.tight_layout()
fig.savefig('输出路径.png', dpi=200, bbox_inches='tight', facecolor='white')
plt.close()
```

## 五、各图型细则

### 5.1 折线/时序图（宏观月报最常用）

```python
ax.plot(x, y1, color='#8B0000', linewidth=2.2, label='系列一', marker='o', markersize=4)
ax.plot(x, y2, color='#4A4A4A', linewidth=2.0, label='系列二', linestyle='--')
ax.plot(x, y3, color='#C9A227', linewidth=1.8, label='系列三')   # 第三系列用金色
ax.axhline(y=50, color='#999999', linewidth=1, linestyle=':', alpha=0.6)  # 荣枯线等基准
```

- 阶段背景：`ax.axvspan(start, end, color='#F5F5F5', alpha=0.5, zorder=0)`，置于数据层下。
- 关键节点标注：上下交替排列，带引线箭头，避免与曲线重叠：

```python
ax.annotate('标注文字', xy=(x0, y0), xytext=(x0, y0 + offset),
            fontsize=15, ha='center', color='#4A4A4A',
            arrowprops=dict(arrowstyle='->', color='#999999', lw=0.8),
            bbox=dict(boxstyle='round,pad=0.3', facecolor='#F5F5F5', edgecolor='#cccccc'))
# offset 对相邻标注正负交替（上 / 下 / 上 / 下）
```

### 5.2 分组柱状图（对比两组数值）

- 组宽 `width=0.35`，两组 x 位置 `x - width/2` 与 `x + width/2`。
- 系列一深红、系列二深灰（`alpha=0.7` 以示区分）。
- 柱顶标数值：`xytext=(0, 3)`，颜色与柱同色，字号 15。

### 5.3 横向条形图（排名类）

- `ax.barh(名称[::-1], 数值[::-1], height=0.6, edgecolor='white')`，倒序使第一名在最上方。
- 颜色规则：第 1 名深红，第 2–4 名深灰，其余 `#999999`。
- 数值标注在条右侧：`ax.text(val + 2, y_center, ...)`，网格改用 `axis='x'`。

### 5.4 对比柱状图 + 提示注释框

- 关键说明用金色边框注释框：

```python
ax.text(x0, y0, '说明文字', fontsize=15, ha='center', color='#C9A227', fontweight='bold',
        bbox=dict(boxstyle='round,pad=0.3', facecolor='#FFF8E1', edgecolor='#C9A227'))
```

### 5.5 饼图（份额类）

- 色序：深红 → 深灰 → 辅助红 → 深灰阶 → 金色 → 灰 → 浅灰（"其他"）。
- `startangle=90`、`pctdistance=0.75`、`labeldistance=1.15`。
- 浅色扇区（"其他"等）的百分比文字改用深灰，其余用白色。

### 5.6 时间线图（政策窗口、事件演进）

- 主轴一条深灰粗线 + 大圆节点（`s=200`，白边）；阶段名在节点上方，说明文字在节点上下**交替**排布并带引线。
- 当前时点标记：深红箭头 + `#FFEBEE` 红底标注框。
- 无坐标轴：`ax.axis('off')`，画布 `figsize=(12, 5)`。

## 六、数据来源标注规范（硬性要求）

- **必须放在图表外部**，时间轴/分类轴**正下方**，用 `fig.text(0.5, -0.02, ...)` 或 `fig.text(0.5, 0.02, ...)`。
- 不得与刻度标签、轴标签重叠；字号 15，深灰 `#4A4A4A`，居中。
- 格式：`数据来源：{机构}《{报告/数据库}》（截至{时间}）`，多来源用顿号连接。

---

## 七、禁止事项（常见反例）

| 禁止           | 正确做法                               |
| ------------ | ---------------------------------- |
| 数据标签压在时间轴刻度上 | 数据来源移到图外底部，标注上下交替                  |
| 图例压住数据曲线/柱子  | 图例固定左上角白底框；必要时缩小 y 轴上限             |
| 网格线盖在数据上方    | `zorder=0` + `set_axisbelow(True)` |
| 彩色背景、花哨渐变    | 纯白背景，阶段区分用极淡色块                     |
| 中文未设字体直接出图   | 每个 fig 前调用 `setup_plot()`          |
| 忘记标注数据来源     | 每张图必须有，且在图外                        |

---

## 八、文件输出规范

- 输出格式 PNG，`dpi=200`，`bbox_inches='tight'`，`facecolor='white'`。
- 默认画布 `figsize=(12, 7)`；时间线图 `(12, 5)`。
- 命名：`chart{序号}_{主题英文缩写}.png`，与文章/报告同目录存放。
- 生成脚本随图表一并保留在工作区，便于后续改数据复用。
